Delivery addresses — dialogs

Every dialog this feature adds or changes, at its true rendered width — 440px for a form, 720px for a per-line ending. Cancel always precedes the primary action in DOM and keyboard order. Each dialog names what changes and what is preserved.

RECORD A CUSTOMER · AC-01 / AC-02 / AC-03

Record a customer

The customer and its first delivery address are recorded together, so it can be chosen the moment you record demand.

An empty name, a name of only spaces, or an empty address is refused in plain language naming which value is not accepted. Nothing is recorded until every one of them is valid.

ADD A DELIVERY ADDRESS · AC-04 / AC-05

Add a delivery address for Nordwind Logistik GmbH

Another place this customer's goods may be sent. Existing orders and frozen lines are untouched.

Make this the main delivery address

An order takes the main address unless the member states another. Hafenstraße 14, 20457 Hamburg is the main one today and would stop being it.

Exactly one active address is the main one at any moment. Marking this one as main is a checkbox in the dialog, not a separate act afterwards.

DEACTIVATE A CUSTOMER · AC-06

Deactivate Rheinmetall Verpackung?

It stops being offered when demand is recorded. Everything already recorded stays exactly as it is.

What stays

Every customer order that names it keeps reading and counting as before, its delivery addresses stay in whatever state they are in, and its name stays taken so no new customer can reuse it.

It can be deactivated while still waiting

This customer has 1 unfulfilled order. Deactivating does not fulfil, cancel or hide it — and you can make the customer active again at any time.

A confirm-only dialog: nothing here is validated, so it takes the alert dialog rather than the form dialog.

RECORD A CUSTOMER ORDER · AC-11 / AC-11a / AC-24

Record what a customer is waiting for

Pick the customer to carry their delivery address, or type a name if they are not a record yet.

A customer of another warehouse is refused without disclosing that it exists there, and an address belonging to a different customer is never offered.

REDIRECT A CUSTOMER ORDER · AC-11b / AC-11c

Redirect this order to another address

It keeps naming Nordwind Logistik GmbH. Only where its goods go changes.

One frozen purchase draft line will report address drift

PD-0142 line 2 ships direct to Hafenstraße 14 and was frozen expecting this order there. Nothing on that draft changes — you are told, and what to do about it is your decision.

Refused against an inactive address, an address of another customer, and an order that is already fulfilled or cancelled — serving a different customer means recording a new order.

DEACTIVATE A DELIVERY ADDRESS · AC-06a / AC-06b

Deactivate Hafenstraße 14, 20457 Hamburg?

It stops being offered wherever a delivery address is chosen.

What stays

Every customer order and every frozen purchase draft line already going there keeps reading and counting exactly as before. Nothing already sent is redirected.

This is the main delivery address

Werftweg 2, 27568 Bremerhaven will become the main one, and you will be told so. A customer never ends up without a main address.

If it were the customer's only remaining active address the dialog would not open — the refusal names that rule instead.

RECORD A DELIVERY TO THE CUSTOMER · AC-19 / AC-20 / AC-21

Record what the customer received on line 2

One line's ending, recorded once. Line 2 of PD-0142 shipped direct to Nordwind Logistik GmbH — Hafenstraße 14, 20457 Hamburg.

This ends line 2 only

The rest of the draft is untouched. PD-0142 moves to Closed when every one of its lines has an ending recorded, and not before.

On-hand quantity does not move

An arrival records that goods reached the transit zone. On-hand changes only when a member sets it to a counted figure and states a reason.

The running total is a live region, so it is announced as the quantities change. Assigning more than arrived, or more than an order still awaits, is refused with every failing bound listed and nothing saved.
