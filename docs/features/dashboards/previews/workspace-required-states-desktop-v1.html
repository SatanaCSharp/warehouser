AC-21 / AC-21a · Granting the observation Permission

The feature’s single addition to stored data. It enters the existing Workspace Role Editor as one more assignable entry in the WAREHOUSES group — not a reserved one, so a custom Workspace Role can carry it (AC-21). The release adds it to every existing Workspace Owner Role with no person acting (AC-21a). Its Permission key is owed by design / data-model.
